# Spanish preterite — extra-large print

Open `index.html` in a browser and select **Print conjugations**. The print layout uses US Letter paper, one verb per sheet, and bold 38-point text throughout (20 sheets total).

Includes the 20 infinitives from the supplied camping exercise, English definitions, and all six preterite forms without subject labels. Forms appear in conventional order: three singular forms followed by three plural forms. Reflexive verbs retain their required reflexive pronouns.
