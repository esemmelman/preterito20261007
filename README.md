# Spanish preterite — extra-large print

Open `index.html` in a browser and select **Print conjugations**. The print layout uses US Letter paper, two verbs per sheet, and 30-point conjugations (10 sheets total).

Includes the 20 infinitives from the supplied camping exercise, English definitions, and all six preterite forms without subject labels. Each table pairs singular forms on the left with plural forms on the right. Reflexive verbs retain their required reflexive pronouns.
